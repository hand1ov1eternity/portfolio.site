## 🎯 Features

- 🚀 **Custom Navigation Bar**  
  A clean, centered logo with links to Home, About, and Resume pages.

- 🧩 **Responsive Grid-Based Project Layout**  
  Displays projects in a flexible 3-column layout on desktop, scaling to a single column on smaller devices. Includes hover animations.

- 🔗 **Social Media Footer**  
  Clickable icons linking to GitHub, Twitter, LinkedIn, and CodePen.

- ♿ **Accessibility Tools with tota11y**  
  Easily test and improve accessibility right from the browser using [tota11y](https://khan.github.io/tota11y/).

---

## 🛠️ Technologies Used

HTML5,
CSS3,
JavaScript (accessibility tools),
Google Fonts,
Responsive design with Flexbox & CSS Grid,
Material Design 3.

---

## 💡 How It’s Built

The project structure is clean and modular, separating content (`HTML`), styling (`SCSS/CSS`), and functionality (`JavaScript`). Responsive techniques are applied with media queries and modern layout tools like **Flexbox** and **Grid**. Design elements are enhanced with **Google Fonts**, and **Material Design 3**.
